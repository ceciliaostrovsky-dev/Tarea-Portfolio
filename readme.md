# Proyecto de Maquetación Web

Este proyecto es una entrega evaluable desarrollada como parte de la formación en el máster Full Stack de Conquer Blocks. El objetivo principal ha sido construir una interfaz web estática, replicando un diseño profesional y aplicando las mejores prácticas de la industria en maquetación y arquitectura de estilos.

## 🚀 Tecnologías Utilizadas

- **HTML5 Semántico:** Estructura web accesible y clara.
- **SCSS:** Arquitectura modular basada en la metodología **BEM**. Uso avanzado de variables, mixins y placeholders para mantener un código escalable, reutilizable y limpio (DRY).
- **Vite:** Herramienta de empaquetado y entorno de desarrollo.
- **CSS Grid & Flexbox:** Posicionamiento moderno para garantizar una experiencia 100% responsiva bajo el enfoque _Mobile-First_.
